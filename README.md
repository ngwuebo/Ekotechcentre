# EkoTech Coaching Centre

Premium mobile-first landing page built with Next.js 15 App Router, TypeScript, TailwindCSS, Framer Motion, React Hook Form, and Zod.

## Setup

1. `npm install`
2. `npm run dev`

## Features

- Mobile-first responsive landing page
- Animated hero, proof, skills, pricing, FAQ, and success pages
- Live countdown to August 6, 2026
- Form validation with React Hook Form and Zod
- Placeholder Paystack payment flow redirect to `/success`
